# 아두이노 버튼 조종기

라즈베리파이에서 돌아가는 게임을 물리 버튼으로 조작한다. 아두이노가 버튼을 읽어
**시리얼로 문자 하나**를 보내고, Pi 쪽 게임이 그 글자를 입력으로 받는다.

```
[버튼] → 아두이노 UNO → USB 시리얼 9600bps → 라즈베리파이 게임
                          'J' 한 글자
```

## 배선 — 버튼 하나, 저항 없이

| 버튼 | 아두이노 |
|---|---|
| 한쪽 다리 | **D2** |
| 다른쪽 다리 | **GND** |

`INPUT_PULLUP` 을 쓰기 때문에 **풀업 저항을 따로 달지 않는다.** 누르지 않으면 `HIGH`,
누르면 `GND` 로 떨어져 `LOW` 다.

> 택트 스위치는 다리가 4개인데 **마주보는 두 쌍이 내부에서 붙어 있다.** 브레드보드에서
> 같은 열에 꽂으면 항상 눌린 것처럼 동작하니, 서로 다른 쌍을 쓰는지 확인한다.

## 업로드

1. Arduino IDE 에서 `controller.ino` 열기
2. **Tools → Board → Arduino Uno**, **Port** 는 UNO 가 잡힌 포트
3. 업로드(→) 후 USB 케이블을 라즈베리파이에 옮겨 꽂는다

## Pi 에서 확인

```bash
ls /dev/ttyACM*        # /dev/ttyACM0  (UNO 는 CDC ACM)
python3 -c "import serial; s=serial.Serial('/dev/ttyACM0',9600,timeout=5); print(s.read(4))"
```

버튼을 네 번 누르면 `b'JJJJ'` 가 나온다. 안 나오면 아래를 확인한다.

| 증상 | 확인 |
|---|---|
| `/dev/ttyACM0` 이 없다 | `lsusb` 에 `Arduino` 가 보이는지. 케이블이 데이터용인지(충전 전용 케이블 주의) |
| 아무것도 안 읽힌다 | **보드레이트가 양쪽 9600 인지.** Arduino IDE 시리얼 모니터를 닫았는지(포트를 잡고 있으면 다른 프로그램이 못 읽는다) |
| 한 번 눌렀는데 여러 번 | 디바운스가 안 먹는 것. `DEBOUNCE_MS` 를 40~50 으로 올린다 |
| 계속 눌린 것처럼 동작 | 택트 스위치 다리 쌍을 잘못 꽂았다 (위 참고) |
| 권한 오류 | `sudo usermod -aG dialout $USER` 후 재로그인, 또는 `sudo` 로 실행 |

## 왜 이렇게 짰나

- **누르는 순간(엣지)에만 보낸다.** 누르고 있는 동안 계속 보내면 게임에서 연타로 처리된다
- **디바운스 25ms.** 접점은 누르는 순간 수 ms 동안 값이 튄다. 그대로 읽으면 한 번 눌러도 여러 번 잡힌다
- **한 글자만 보낸다.** 게임 쪽은 `ser.read()` 로 1바이트를 읽는 구조라, 줄바꿈이나 문자열을 보내면 파싱이 필요해진다

## 버튼을 늘리려면

```cpp
const int PINS[]   = {2, 3, 4};
const char CHARS[] = {'J', 'L', 'R'};   // 점프 · 왼쪽 · 오른쪽
```

핀마다 위 디바운스 로직을 같은 방식으로 돌리고 문자만 다르게 보낸다. 게임 쪽에서는
받은 글자로 분기하면 된다.

## 조종기 없이 테스트하려면

`pygame-on-lcd.py` 런처가 **LCD 터치 탭을 같은 문자로 주입**한다. 아두이노를 연결하지
않아도 화면을 만져서 플레이할 수 있다.

```bash
sudo python3 pygame-on-lcd.py your-game.py --key J
```
